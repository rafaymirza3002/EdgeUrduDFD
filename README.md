# Urdu Deepfake Detector — Module 2 Starter

Implements **Module 2: Dual-Mode Audio Ingestion and Quality Assurance**.

## Setup

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# Linux/macOS
source .venv/bin/activate

python -m pip install --upgrade pip
pip install -e ".[dev]"
pytest
streamlit run streamlit_app.py
```
